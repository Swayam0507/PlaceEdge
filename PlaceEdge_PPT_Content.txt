Slide 2: Problem Statement (Suggested Addition)
---------------------------------------------------------
• Fragmented Preparation: Students juggle multiple platforms for coding, aptitude, and resume building.
• Lack of Personalized Feedback: TPOs (Training & Placement Officers) cannot manually review hundreds of resumes or take mock interviews for everyone.
• Uncertainty in Placements: Students don't know their actual standing or probability of getting placed based on their current academic metrics.
• Manual Tracking: Keeping track of company drives and eligibility is tedious and error-prone.

Slide 3: About Project Overview
---------------------------------------------------------
• What is PlaceEdge?: A unified, premium SAAS-like platform designed to streamline the placement journey for students and college administration.
• Core Goal: Bridge the gap between student skills and industry expectations using Artificial Intelligence and Machine Learning.
• Key Value: Provides end-to-end support—from tracking company visits to evaluating resumes, practicing mock interviews, and predicting placement success.

Slide 4: Key Features of PlaceEdge
---------------------------------------------------------
1. Company Tracker & Eligibility Checker: Automated matching of student profiles with company criteria (CGPA, backlogs, etc.).
2. AI ATS Resume Analyzer: Parses resumes and gives an ATS score with actionable improvement tips.
3. Interactive Practice Hub: Aptitude and technical coding questions tailored to specific job roles.
4. Admin Analytics Dashboard: Comprehensive view for TPOs to track student progress, success rates, and company pipelines.
5. Premium UI/UX: Custom "PlaceEdge Theme" with dynamic glassmorphism and modern aesthetics.

Slide 5: The ML Engine (Placement Predictor)
---------------------------------------------------------
• Purpose: Predicts the probability of a student getting placed in a specific tier of companies.
• Input Features: Current CGPA, number of active/dead backlogs, mock test scores, technical skills rating, and internship count.
• How it works: 
  - Uses historical placement data to train predictive models (e.g., Random Forest / Logistic Regression).
  - Outputs a percentage probability and highlights "Weak Areas" (e.g., "Improve Aptitude Score to increase chances by 15%").

Slide 6: Frontend Technology Stack
---------------------------------------------------------
• Core Framework: React.js (Vite for fast bundling)
• Styling: Tailwind CSS (Custom Design System with bespoke color tokens like Amber-Deep, Emerald, Ink, Surface)
• Animations: Framer Motion for fluid, micro-interaction animations
• Icons & Graphics: Lucide-React (High-quality SVG icons)
• Routing: React Router DOM (Role-based Protected Routes for Admin vs. Student)

Slide 7: Backend & AI Stack
---------------------------------------------------------
• Server Runtime: Node.js with Express.js REST API
• Database: MongoDB (Mongoose ODM) for flexible schema design (Users, Companies, Test Histories)
• Authentication: JWT (JSON Web Tokens) for secure, stateless sessions
• AI Integration: Generative AI (Google Gemini API / OpenAI API) used for:
  - Generating dynamic technical interview questions
  - Evaluating student answers and providing personalized feedback
  - Parsing and scoring resumes

Slide 8: Architecture & Workflow
---------------------------------------------------------
1. User Onboarding: Role-based login (Student / Admin).
2. Data Flow: React client makes RESTful HTTP calls to the Node/Express backend.
3. AI/ML Processing: 
   - Backend routes prompt data to the LLM API for dynamic text generation (Resumes/Interviews).
   - Numerical data is routed to the ML models for prediction scoring.
4. Database Layer: MongoDB securely stores and retrieves real-time statistics for the Admin Dashboard.
5. Response: JSON data is sent back to the client and rendered dynamically with Framer Motion.

Slide 9: Merits (Advantages)
---------------------------------------------------------
• Centralized Hub: Replaces 4-5 different tools with a single platform.
• Highly Scalable: Can easily accommodate thousands of students across multiple college branches.
• Time-Saving for Admins: Automates eligibility checking and progress tracking.
• 24/7 AI Mentorship: Students get immediate, unbiased feedback on their skills anytime.

Slide 10: Demerits (Limitations)
---------------------------------------------------------
• AI Hallucinations: Generative AI might occasionally provide generic or slightly inaccurate feedback.
• Data Dependency: The ML Predictor's accuracy heavily relies on the quality and volume of historical training data.
• Internet Requirement: As a cloud-based web app, it requires a constant, stable internet connection.

Slide 11: Future Scope
---------------------------------------------------------
• Real-time AI Video Interviews: Integrating WebRTC for live AI avatar-based mock interviews.
• Direct Recruiter Portal: Allowing actual companies to log in, shortlist candidates, and conduct tests on the platform.
• Mobile App: Launching a React Native mobile application for on-the-go notifications and quick aptitude practice.
• Alumni Network Integration: Connecting current students with placed alumni for direct referrals.

Slide 12: Conclusion
---------------------------------------------------------
• Summary: PlaceEdge revolutionizes campus placements by combining modern web technologies with cutting-edge AI.
• Final Thought: It empowers students to be industry-ready and equips institutions with data-driven insights.
